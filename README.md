# Encore Salon Suites Atlanta: landing page (staging)

Staging preview of a redesigned landing page for the Atlanta/Midtown location.
Not the live site. The page is marked noindex and robots.txt blocks crawlers.

- `index.html`: the page (single file, no build step)
- `img/`: optimized photos and logo

The tour form is not connected yet. Set `ENDPOINT` in the script at the bottom of `index.html` to the CRM / Gravity Forms endpoint before launch.
